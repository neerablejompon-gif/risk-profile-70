# Risk Profile 2570: ระบบรายงานผลการบริหารความเสี่ยง

เว็บแอปไฟล์เดียว (HTML + vanilla JS) สำหรับทำรายงานผลการบริหารความเสี่ยงระดับองค์กร

- นำเข้าแบบฟอร์ม Excel "ผลความเสี่ยง ไตรมาส" (ชีท `KRI` และชีทต่อสาเหตุชื่อ `S1 (R1)`)
- แก้ไขข้อมูลได้ทุกช่องตามแบบฟอร์ม ระบบบันทึกอัตโนมัติในเบราว์เซอร์ และบันทึก/เปิดเป็นไฟล์ `.json` ได้
- ส่งออก **PDF A4 แนวตั้ง** ได้ 2 แบบ คือฉบับเต็มและ Risk Profile
- ส่งออก **PNG แนวนอน** หน้าละ 1 ปัจจัยเสี่ยง (.zip หรือทีละหน้า) เลือกความละเอียดได้ 150/200/300 dpi
- Risk Assessment Matrix 5×5 แสดงตำแหน่งก่อนและหลังบริหาร พร้อมเส้นขอบเขตความเสี่ยงที่ยอมรับได้

## ใช้งาน
เปิด `index.html` ในเบราว์เซอร์ หรือเปิดใช้ GitHub Pages จาก branch `main` ได้เลย ไลบรารี (SheetJS, html2canvas, jsPDF, JSZip) โหลดจาก cdnjs เมื่อกดใช้งานเท่านั้น

## พัฒนา
```
python3 scripts/build.py   # รวม src/app.src.html + src/parser.js เป็น index.html
```
ถ้ามีไฟล์ `data/sample.json` ระบบจะฝังเป็นข้อมูลตัวอย่างตอน build ไฟล์นี้อยู่ใน `.gitignore` เพื่อไม่ให้ข้อมูลจริงขององค์กรขึ้น repo สาธารณะ

ไฟล์หลัก
- `src/app.src.html`: UI, การแบ่งหน้า A4, รูปแบบรายงาน, การส่งออก
- `src/parser.js`: ตัวอ่านแบบฟอร์ม Excel
